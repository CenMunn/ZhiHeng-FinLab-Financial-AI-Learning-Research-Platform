# 架构与算法深入审阅

日期：2026-10-14。用户已认可原设计，并要求再次审阅、细化和寻找创新点。范围：三个独立的架构/算法/交互审阅与根审阅综合；已核对原规格、现有惠天案例、技能规范和相关一手文献。

结论：保留总体架构；先补金融语义、训练任务边界、保存一致性与业务交互。首版只实现必要模块，首个研究假设收敛为金融混淆负例训练。没有证据支持宣称新模型优于基线，也没有完成学术新颖性查重。

## 审阅发现与处理

以下是实施前的设计缺口，不是已复现的运行时 bug。“已修订”指写入设计，仍需实现与测试。

| ID / 优先级 | 具体失败场景 | 本轮处理 | 后续验证 |
|---|---|---|---|
| R01 / 首版必须 | 缺少基准账期却允许提前 30 天，可能计算出不可实现的释放 | M1 仅开放非负延迟；主输出改为稳态应收占款变化 | 参数边界、单调性；确认页面未承诺真实现金释放 |
| R02 / 首版必须 | 惠天的供暖季节性被一个年均公式和“现金影响”主卡掩盖 | 保留案例但结果旁显示年均简化；不画实际周现金余额，不给概率 | 仅阅读结果区就能识别假设与局限 |
| R03 / 首版必须 | 只校验客户端 hash 就保存，或 SQLite 记录引用尚未写成功的快照 | 服务端读可信快照重算；输入、结果、来源与幂等记录同事务 | 篡改结果、写入失败、同键异参、重试 |

| R05 / 首版必须 | 原方案只写 Decimal，先四舍五入日均值会得到不同结果 | 固定精度、顺序、最终舍入与规范 hash | 100×1×90/365 得 24.66，而非 24.30 |
| R06 / 首版必须 | 草稿已变但旧响应完成，界面把旧结果标为当前；跨报告直接算“改善” | 具体状态机、比较锚点、参数差异与版本约束 | 慢响应、保存失败、换案例、跨口径比较 |

| R08 / 训练前必须 | 少答题/补 gold/排除召回失败，制造好看的覆盖成绩 | 冻结完整标注证据 Coverage@5；保持分母；条件指标另报 | 指标夹具、标签访问隔离、召回上限核查 |
| R09 / 接入中文前必须 | 英文训练效果直接替换中文排序，导致单位/范围错误增加 | 单独中文迁移诊断，原模型与微调模型成对比较 | 自然中文案例，分错误类型报告 |
| R10 / 后续优化前必须 | 按未来真实收款提前决策，或把付款推到第 14 周降低 13 周成本 | 滚动时点信息、当前决策非预知、期末债务与未付约束 | 无全知信息的回测、终端成本/约束、不可行报告 |

## 哪些创新值得投入

| 候选 | 价值 | 首次可交付内容 | 范围 |
|---|---|---|---|
| 金融语义混淆负例训练 | 针对“看起来相关但财务含义错误”的排序失败，形成可训练的研究问题 | 普通困难负例 vs 金融混淆负例，同模型/数据/预算对照，含负结果 | 首要研究假设；先检查数据能否支持 |
| 可追溯的情景差分 | 用户能看懂结果为何变化，把交互与财务解释连接起来 | 假设变化、固定来源、公式、差值联动 | 纳入 M1 的轻量交互 |
| 证据充分性与选择性回答 | 缺依据时减少错误回答 | 相同回答覆盖率下比较错误率/错拒率 | 后续候选，不阻塞首轮 |
| 预测到资金决策的效果评估 | 检查预测误差改善是否真的降低资金损失 | 同一 LP 下比较融资成本、底线违反、终端债务 | 有数据与稳定现金引擎后开展 |

“金融困难负例”“元数据检索”“预测后优化”均有既有研究基础。可归于本项目的成果是问题定义、数据与错误类型、实验设计、实际训练及可复现结论。需要完成系统文献比较与实验后，才判断是否有新的研究贡献；不写“首创”或保证发表/比赛名次。

主假设数据不足时交付普通基线和失败分析，不人为制作伪财务材料维持创新叙事。数据足够但增强无增益，也作为有效实验结果保存。

## 有意暂缓的建议

- 不增加通用插件系统、微服务集群、数据库式血缘图和复杂模型注册平台；先用对象 ID、快照与版本完成必要追溯。
- 不同时启动多个公开数据集、多个大模型微调和多智能体系统；FinQA 的任务边界清楚后，完成一个模型主线。
- 不为 M1 引入现金流神经网络；它的公式是教学/研究用静态敏感性估算，复杂度不应被包装成效果。
- 不把 UI 动画数量作为交互质量；Interactive-front-end 的微交互规范已足够，本轮补的是业务状态、比较与追溯。

- [T²-RAGBench](https://aclanthology.org/2026.eacl-long.8/)讨论上下文依赖 QA 与真实检索的差异，支持任务分开；本轮未复现其结果。
- [元数据 RAG 研究](https://arxiv.org/html/2510.24402v1)的方法/实验结构已有相关机制，支持对创新措辞保持克制；该来源为预印本。

没有读取既有保留集，没有训练或实际页面验证。数学夹具复算及文档/来源检查记录在 [review-validation.json](review-validation.json)。原架构/研究路线/进度的审阅前版本保存在 [压缩快照](2026-10-14-before-review.zip)，独立审阅中的原行号以该快照为准。
