# 滚动验证 → 特征诊断 → 冻结预训练编码器

用户已授权继续此顺序。本轮为新D21协议，不覆盖D20固定划分模型/成绩；复用公开快照、60期已知收盘收益和可执行open→open标签。

## 预先冻结

- 2024Q1至2025Q4共8折；每折train从2018开始扩展，validation为评估前12个日历月，evaluation为下一季度。各段要求entry/exit均在段内、标签在段截止后00:01UTC前成熟；历史特征预热可越段，未来标签不能越段。
- 复用四基线、固定LightGBM、每折DLinear三种子及训练/验证早停预算，参数同D20。每折缩放只拟合本折train。评估特征/标签分离，先冻结全部预测，再由独立进程评分。不是未知盲测，2024–2025行情已被研究过。
- 固定特征分组：动量mean5/20；波动std5/20；K线range/intraday/已知gap；60期累计路径回撤。所有值仅从决策时点已知OHLC/分红/收益构造。成交量不进入模型（A股源有手数舍入）。LightGBM增强组与4个分组剔除消融全报告，不按评估选组；不同输入与同输入模型对照分开标明。
- 验证段做分组20行块置换5次，报告MSE增量及重复间波动；评估段只做label-free分布漂移（train分位数边界PSI、常量/未知区分）。不以重要性声称因果解释，不用评估标签筛选特征。
- 各折误差、方向、MSE skill与20期/2000次配对块区间；总体用拼接逐条预测计算加权误差，不能平均各折RMSE冒充总体。CI只在各折内，不跨折拼成独立日样本。冻结规则仓位0/1，季度最后可评分退出日目标现金，边界缺标签日保持现金，连续单一资金账本；成本敏感性0×/1×/2×（固定预测）单独比较。
- 先完成滚动及诊断，再接Chronos：amazon/chronos-t5-tiny固定2024-03-27 commit129a2d204d6ab4205a0049a160402deefaf161b2，只下载config/generation_config/README/safetensors，核对LFS SHA和Apache2许可。训练数据具体截止与早期金融重叠未知；只将2025四折纳入预训练比较。
- 使用官方chronos-forecasting1.5.3 embed，冻结8M基座，历史60期输入→mean-pool编码表示→train-only标准化+alpha10岭读出（目标与其他模型相同）。这是监督读出适配，不是零样本收益预测，也不是基座全参数微调。保留原始收益岭回归与从相同T5配置随机初始化编码器+同读出控制，以区分预训练与架构/维度效应。所有2025比较模型使用同一行集合，随机控制固定42。
- 在research/.venv与已授权GPU运行；API只读，模型/输入/预测/来源独立指纹，缺产物提示/篡改拒绝。保持旧数据/旧模型结果及原账号数据库。预训练检查不满足则如实保留失败，不能用演示结果补齐。

## 文件与执行

1. research/rolling/data.py：折边界/清除、因果特征；tests先验证未来不影响过去、分组计算、成熟时间/季度/闰年。
2. acquire.py/pretrained.py：固定来源元数据/许可/哈希下载、官方冻结嵌入/随机控制、训练段读出。模型只加载本地安全权重，不执行仓库远程代码；新依赖锁定。
3. pipeline.py：生成每折兼容D20训练输入，复用原runner的smoke/train/predict（旧源码不变），增强/消融/诊断独立；先滚动基线诊断，后预训练与冻结预测。
4. score.py：独立读取评估标签、拼接/各折/成本敏感性/连续资金账本，发布自足只读D21结果；新API与旧模型结果隔离，网页展示滚动图、折详情、诊断与2025预训练对照。
5. 真实训练/下载/评分；单测、构建、浏览器与独立审阅；更新状态、结果、限制与可复现命令。不把本轮历史分析标为最终投资结论。
