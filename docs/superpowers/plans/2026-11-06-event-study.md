# D28 公告数据资格与单事件教学回放

> 使用subagent-driven-development分工：公告与证据、市场数据与数学引擎、API/交互界面独立实现；根任务编排发布与独立验收。复用当前工作区，不提交其他未提交改动。

**目标：** 执行用户认可的第四阶段首个切片：完整审计固定公告目录，并把一个预先选定事件的原文事实、时间映射、AR/CAR及局限串成可操作学习流程。

**架构：** `research/event_study`负责公开采集、PDF证据和冻结发布；`experiments/event_study.py`纯计算；只读store/API加显式参数预览；量化实验室新增独立教学区域，智投委仍负责其原认证证据工作区。原账号/模型/D27前向任务不改变。

## 已授权范围与实施判断

- 目录按公告发布日期2024-01-01至2025-12-31取样，固定600519/600036/600585，报告所属期间另列。保留定期报告全文、摘要、更正关系及不合格原因，来源分页与计数可追溯。
- 原文来源优先交易所/指定披露平台。公告只提供日期时，不把午夜字段当真实发布时刻；用严格下一交易日映射事件0日，注明保守代理，不证明历史首次可用。
- 首个案例预先固定茅台2024年一季报，不按收益挑选；只下载此PDF并核对营业收入、归母净利润、经营活动现金流净额的单位/期间/范围/页码。时间或证据不可靠时阻塞相应能力。
- 日收益：个股收盘总收益（含当日现金分红），沪深300价格指数日收益；两者口径差异明确。原股价使用D24来源归档，指数另做有界公开获取并冻结。
- 市场模型OLS `r_stock=alpha+beta*r_market+epsilon`，估计窗口固定相对事件[-130,-21]110交易日，不随用户观察窗口改变；事件默认[-5,+5]，前/后各可选1..10。缺口/非有限/零市场方差/样本不足拒绝。
- AR为实际收益减拟合正常收益，CAR为窗口累计AR。窗口改变是探索性敏感性，不按最好结果推荐；单事件关联不等因果，非交易回测，不称PEAD。
- 规则抽取与人工核对可先实际落地；模型组必须真的执行后才计准确率。本切片不调用付费模型，不用现有英文检索成绩冒充中文抽取成绩，也不制造gold。
- 学习假设只作当前本地交互，不伪称历史预注册；公开案例证据可链接原文，原智投委私有文档仍走原认证。

## 重点审阅

日期不等于精确首次发布时间；摘要/全文不能双算事件；修订不是新盈利信息的默认标签；估计窗口和事件窗口不得重叠；当前报表可见内容不自动等于历史版本；PDF物理页与印刷页分开。数值/来源不合格时留原因而非填补，参考论文为MacKinlay1997事件研究方法。
